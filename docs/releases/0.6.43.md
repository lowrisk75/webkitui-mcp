# WebKitUI MCP 0.6.43 Developer Preview

For Apple silicon Macs running macOS 15 or later. Source available under BUSL-1.1;
commercial production use requires the agreement described in LICENSING.md.

## Changes

- An idempotency key whose gesture was definitely not dispatched now survives
  re-observation of the same intent. Observation-scoped handles may change;
  changed intent or any dispatched attempt still cannot reuse the key.
- New `dialog_contains` postcondition: the exact accessible dialog name and the
  requested `item_text` substring must match one unique dialog in the action's
  frame. Pre-existing matches, duplicate matches and incomplete dialog evidence
  cannot prove a new transition. An unrelated truncated footer does not block
  complete dialog evidence. This does not prove causality or a backend save.
- Transaction results include structured recovery evidence and the exact read-only
  reconciliation call to use with the original session/key. No automatic replay.
- Unlabeled textareas no longer borrow their contents as an accessible name.
  A unique observed HTML name can preserve identity across a controlled rerender;
  missing, changed or duplicated identity cannot verify the fill.
- The global privacy inventory supports up to 512 roots, with a new shared
  20,000-element traversal bound. Existing sensitive-value/character limits remain.
  Extraction still refuses if the complete inventory cannot finish; it never
  returns a partly filtered page. This is not a general Reddit compatibility claim.
- **Report this site…** lets a person review a voluntary report before opening
  their mail client's draft to support@lorislab.fr. It includes origin, app metadata,
  load counters and allowlisted structure around a supplied label. No screenshots,
  field values, URL paths/queries, CSS class values or arbitrary custom names.
  Collection and artifact size are bounded; the app does not send the report.

- Native clean checkouts no longer depend on ignored legacy npm files for licence
  tests or source provenance. Retained prior-art fixtures stay outside release inputs.

## Install and compatibility

Download the notarized ZIP and verify it with SHA256SUMS. Finish active browser
tasks, quit WebKitUI MCP, replace the app in Applications, then relaunch. Restart
existing MCP conversations to refresh their tool catalog. App replacement preserves
profiles, sign-ins and license state; live pages do not survive a restart.

Receipts can now contain new contextual-predicate cases. Do not downgrade a receipt
store that has recorded these transactions to 0.6.42; use a forward fix rather than
deleting replay memory to make a downgrade work. Retain the previous notarized
archive for recovery before adopting the new receipt format.

## Validation scope

Local Debug, Release, native/JavaScript fixtures, privacy adversarial cases, signing,
archive and notarization checks are recorded with the release evidence. Synthetic
fixtures do not establish authenticated Reddit/ASC compatibility, server-side
persistence, or Mail delivery. Safari fallback remains manual and does not transfer
cookies or credentials. This remains a Developer Preview.
